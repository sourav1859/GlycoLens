# GlycoLens Documentation Governance

1. Read `AGENTS.md`, `docs/planning/GlycoLens_00_README.md`, and `docs/planning/GlycoLens_01_Updated_Project_Summary.md`.
2. Inspect the request and complete diff; identify changed decisions rather than matching filenames mechanically.
3. Read [references/planning-impact-map.md](references/planning-impact-map.md) and open every affected planning document.
4. Update all affected files in the same work cycle. Update the root README when setup, status, or navigation changes.
5. Check terminology, cross-links, dates, model names, safety language, and contradictions across the pack.
6. Report every planning document reviewed, whether it changed, and the reason.

Do not rewrite scientific hypotheses, model choices, features, or safety boundaries merely to mention tooling. Preserve source-of-truth content that the implementation did not change.
