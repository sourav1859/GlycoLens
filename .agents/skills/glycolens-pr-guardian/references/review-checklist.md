# Review Checklist

- Behavior matches acceptance criteria and safe failure expectations.
- Medical boundary remains research/education only.
- No secret, token, PHI, private export, dataset, weight, cache, binary surprise, or generated graph output is included.
- Server/client secret boundaries and database authorization are correct.
- Forecast and data changes prevent temporal and subject leakage.
- Tests cover changed behavior at appropriate layers without brittle duplication.
- Planning documents, README navigation, ADRs, and operational guidance are synchronized.
- Performance or model-quality claims link reproducible evidence.
- Migration and rollback are defined for schema, API, or stored-data changes.
- Graphify was refreshed or its status is disclosed; graph claims were source-verified.
