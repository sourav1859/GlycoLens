# Coverage Requirements

## Playwright

Cover the critical meal-to-forecast flow, mobile viewport, keyboard navigation, accessible names and focus, loading/error states, slow network, external nutrition fallback, uncertainty, and safety messaging.

## APIs

Validate schemas, authentication and authorization boundaries, malformed payloads, idempotency, rate or abuse behavior where applicable, timeout/retry policy, and stable error contracts.

## Database

Test row-level-security isolation, ownership, migration behavior, sanitized seeds, and denial by default.

## Scientific and ML evaluation

Test timestamp cutoffs, meal-window boundaries, future-event exclusion, subject-disjoint and temporal splits, retrieval chronology, persistence-baseline reproducibility, metric calculations, uncertainty coverage, and unusable-run accounting.

## Traceability row

Record requirement/risk, scenario, layer, fixture, expected evidence, implementation location, and result.
